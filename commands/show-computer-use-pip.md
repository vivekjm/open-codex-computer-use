# Show Computer Use PiP

Open the floating **Currently Sharing** preview (same pattern as Codex Picture in Picture). Do not bring Simulator or the target app to the front.

```sh
./scripts/computer-use-pip.sh show Simulator
```

If the user named another app, pass that name instead of `Simulator`. Then continue the GUI task with Open Computer Use MCP/CLI tools in the background.
