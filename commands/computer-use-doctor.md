# Computer Use doctor

Run `./scripts/doctor.sh`. Report concrete failures and the exact repair command. Use `--repair` only when installation/build repair is appropriate, `--live` for an MCP handshake, and `--permissions` only when the user asks or a real TCC error occurred.
